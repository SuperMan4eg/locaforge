# История изменений

Все заметные изменения LocaForge документируются в этом файле.

## Не выпущено

## 0.4.0 — 2026-08-10

- Постоянная история Undo/Redo расширена на approve/reopen и lock/unlock, включая атомарные
  записи истории для пакетных review-операций.
- Пункты меню Undo и Redo теперь называют конкретную операцию.
- Replace, Apply to matches и Restore revision участвуют в постоянных Undo/Redo как атомарные операции.
- Результаты AI Review, варианты reviewer и созданные QA issues можно отменять и повторять,
  включая завершённую часть отменённого многопакетного review.
- Отклонение одной или нескольких находок AI review обратимо через ту же историю Undo/Redo.
- Undo/Redo проверяет снимки QA issues вместе с полями записей и не даёт старой операции
  перезаписать результаты более новой проверки.
- Панель History показывает последние операции проекта, время, применённое/отменённое состояние
  и количество затронутых записей.
- При создании и настройке проекта можно создать редактируемый структурированный профиль по
  имени проекта с помощью настроенной локальной модели Ollama.
- Профиль создаётся в фоновом worker с видимым busy state, поэтому медленный ответ модели не
  замораживает диалог проекта.
- При явном разрешении в Privacy и выборе в диалоге проекта создание профиля может дополнить
  prompt ограниченными фрагментами поиска Wikipedia; исходные строки локализации не отправляются.
- Меню File теперь содержит одну команду Import files и проектные Export selected / Export all
  вместо отдельных команд по форматам.
- Дерево файлов проекта поддерживает мгновенную фильтрацию по имени и относительному пути;
  выбор отфильтрованной папки затрагивает только видимые совпадения.
- Навигация вкладки Project направляет Ctrl+F в поиск файлов, Ctrl+A выбирает все видимые файлы,
  Escape очищает активный фильтр или выделение.
- Вкладка Project показывает число видимых/всех и выбранных файлов, явно задавая область
  пакетного экспорта, обновления и удаления.
- Предпросмотр единого импорта находит конфликты путей без учёта регистра с файлами проекта
  и блокирует импорт до открытия диалогов mapping.
- Пути проекта редактируются прямо в предпросмотре импорта с живой проверкой уникальности и
  безопасности, чтобы исправлять конфликты без повторного выбора файлов.
- Единый импорт может одной операцией добавить безопасную папку назначения ко всем файлам.

### Добавлено

- Project-first workflow: пустой проект с описательным профилем создаётся до импорта файлов.
- Одна команда множественного выбора добавляет JSON, CSV/TSV, PO и XML, сохраняя шаги mapping.
- Project Explorer поддерживает Windows-style multiselect, фильтрует таблицу, экспортирует
  выбранные файлы и открывает настройки проекта.
- Добавлены рабочие области Translations и Project с деталями файлов, статистикой, навигацией
  по двойному щелчку и контекстным меню файловых операций.
- Добавлен категоризированный диалог Settings для оформления, editor, autosave, подтверждений
  import/export, языков проекта по умолчанию и privacy.
- Метаданные профиля собираются в ограниченный предпросматриваемый AI-контекст для prompts
  перевода и reviewer.
- Неудачное открытие проекта может восстановиться из автоматической `.lfproj.bak`, не
  перезаписывая повреждённый оригинал или резервную копию.
- Undo пакетного перевода поддерживает постоянный Redo через `Ctrl+Shift+Z`, включая варианты,
  workflow status и validation issues.
- Единый импорт принимает drag-and-drop файлов и папок, рекурсивно ищет форматы и показывает
  полный набор до mapping/import.
- Импорт папок сохраняет относительные пути, допускает одноимённые файлы в разных каталогах
  и восстанавливает дерево при пакетном экспорте.
- Project показывает настоящее раскрываемое дерево с колонками формата и прогресса; папка
  выбирает все файлы локализации ниже неё.
- Выбранные документы и ветви удаляются транзакционно; исходники не затрагиваются, связанные
  записи, QA и история очищаются.
- Импортированные документы сохраняют исходное расположение для обновления; дерево Project
  может открыть его в системном файловом менеджере.
- Выбранные документы обновляются из источника с предпросмотром новых/изменённых/удалённых
  записей; стабильные записи сохраняют переводы, изменённые возвращаются на review.
- Ручные правки перевода включены в постоянную историю Ctrl+Z/Ctrl+Shift+Z с восстановлением
  workflow status и validation state.

### Изменено

- Меню File теперь сосредоточено на New Project, Open Project и Add Files вместо отдельных
  команд создания проекта для каждого формата.

## 0.3.0 — 2026-08-09

### Добавлено

- Многофайловые проекты `.lfproj`, смешанный пакетный импорт, фильтрация по файлам, статистика
  документов и транзакционный пакетный экспорт с исходными именами.
- Раздельные варианты моделей перевода и reviewer с явным выбором версии.
- Undo операций перевода через `Ctrl+Z`, включая состояние пакета, вариант, status и validation
  после повторного открытия проекта.
- Поиск по полям таблицы, полные tooltips, меню Models и подробная сводка создания проекта.

### Изменено

- Метаданные `.lfproj` обновлены до версии 2 с автоматическим открытием и миграцией версии 1
  и старых схем SQLite.
- Контракт reviewer Ollama дополнен необязательным исправленным переводом с совместимостью
  с прежними ответами только со списком issues.

## 0.2.0 — 2026-08-05

### Добавлено

- Import/export CSV/TSV, Gettext PO и XML с сохранением формата.
- Translation memory, glossary, история revisions, фильтры validation и AI-assisted review.
- Переиспользуемые профили mapping JSON и навигация по недавним проектам.
- Autosave, структурированное логирование, настраиваемые модели Ollama и их установка.
- Portable-сборка Windows и автоматический smoke test упакованного приложения.
- GitHub Releases по тегам с Python-пакетами, Windows ZIP и SHA-256 checksums.

### Изменено

- Desktop orchestration разделён на специализированные presentation controllers; добавлены
  smoke tests композиции GUI.
- Область продукта и release-документация расширены за пределы исходного JSON-only MVP.

## 0.1.0 — 2026-08-04

- Первый local-first релиз для JSON-локализации с проектами `.lfproj`, переводом Ollama,
  защитой placeholders, валидацией и desktop-интерфейсом PySide6.
