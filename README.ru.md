# LocaForge

LocaForge — локальная desktop CAT-платформа для перевода игр, приложений и программного
обеспечения с помощью локальных языковых моделей. Исходные файлы остаются на компьютере
пользователя и никогда не изменяются напрямую.

> Проект находится в активной разработке. Текущая версия: `0.4.2`.

## Возможности

- импорт и экспорт JSON, CSV/TSV, Gettext PO и XML с сохранением формата;
- многофайловые проекты со смешанными форматами в переносимых SQLite/ZIP-контейнерах `.lfproj`;
- ручное и пакетное редактирование, глоссарий, память переводов, история версий и review;
- локальный перевод и AI review через Ollama с раздельным выбором моделей;
- защита placeholders, валидация, постоянные Undo/Redo и общепроектная история;
- необязательные структурированные профили проектов для контекста модели;
- desktop-интерфейс на PySide6 с английской, русской и пользовательскими локализациями.

## Требования

- Python 3.12 или новее для запуска из исходного кода;
- [Ollama](https://ollama.com/) для локального AI-перевода и review.

## Установка и запуск

### Готовая сборка для Windows

Скачайте `LocaForge-0.4.2-windows-x64.zip` со страницы
[последнего релиза](https://github.com/SuperMan4eg/locaforge/releases/latest), распакуйте
архив и запустите `LocaForge.exe`. Python уже включён; Ollama устанавливается отдельно.

### Из исходного кода

```powershell
git clone https://github.com/SuperMan4eg/locaforge.git
cd locaforge
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
locaforge
```

Приложение также запускается командой `python -m locaforge`.

## Настройки моделей

Настройки приложения задают глобальные модели Ollama, prompts, режимы reasoning, timeout и
размер пакета. Проект наследует актуальные глобальные значения, пока в его настройках не
включён параметр **Переопределить глобальные настройки моделей**. При включении текущие
эффективные значения копируются в проект, и последующие глобальные изменения на него не
влияют. Отключение возвращает наследование. Подробности хранения и миграции приведены в
[руководстве разработчика](docs/development.ru.md#наследование-настроек-моделей).

## Пользовательские языки интерфейса

Языковые пакеты — JSON-файлы из пользовательского каталога локализаций. Возьмите созданный
приложением `template.json`, переведите сообщения, не меняя ключи и именованные параметры,
сохраните под новым именем, затем перезагрузите и проверьте пакет в настройках. Полный формат
и устранение ошибок описаны в [руководстве по локализации](docs/localization.ru.md).

## Диагностика и конфиденциальность

На панели журнала есть команда **Копировать диагностику** для обращений за поддержкой. Отчёт
содержит версии приложения, Python, PySide, Qt и ОС, а также сводные количества и форматы проекта.
Он никогда не включает имя проекта, пути, исходные строки, переводы, промпты или содержимое
журнала. Сообщения журнала, скопированные вручную, следует отдельно проверить перед отправкой.
После неожиданного сбоя отчёт также включает короткий ID инцидента из сообщения об ошибке: он
позволяет сопоставить отчёт с локальной traceback, не помещая саму traceback в буфер обмена.

## Разработка

```powershell
$env:PYTHONPATH = "src"
$env:QT_QPA_PLATFORM = "offscreen"
python -m pytest
python -m ruff check src tests
python -m mypy src
python scripts/check_docs.py
```

CI выполняет проверки качества на Python 3.12 и 3.13, собирает Python-пакеты и проверенную
portable-сборку Windows, а также проверяет языковые пары и ссылки документации.
