# Создание пользовательской локализации интерфейса

LocaForge включает английский и русский языки и загружает дополнительные JSON-пакеты из
пользовательского каталога локализаций. В Settings → Language можно найти этот каталог,
перезагрузить пакеты и посмотреть диагностику проверки.

## Создание пакета

1. Один раз запустите LocaForge: в пользовательском каталоге появится `template.json`.
2. Скопируйте шаблон в файл с понятным именем, например `de.json`; сам шаблон не изменяйте.
3. Задайте BCP 47-подобный код в `metadata.locale` и отображаемое имя в `metadata.name`.
4. Переведите значения `messages`, сохранив все ключи и `{именованные_параметры}`.
5. Сохраните UTF-8 JSON, перезагрузите пакеты в Settings и исправьте все ошибки.
6. Выберите новый язык. Региональный запрос вроде `de-DE` сначала ищет установленный пакет
   базового языка, а затем использует английский.

Минимальная структура:

```json
{
  "metadata": {
    "locale": "de",
    "name": "Deutsch",
    "fallback": "en",
    "format_version": 1
  },
  "messages": {
    "app.title": "LocaForge",
    "example.count": "{count} Einträge"
  }
}
```

Используйте полный созданный шаблон: сокращённый пример не является готовым пакетом.

## Правила проверки

- корень содержит объекты `metadata` и `messages`;
- `locale`, `name` и `fallback` — непустые строки;
- `fallback` равен `en`, а `format_version` равен `1`;
- ключи и значения сообщений — непустые строки;
- пользовательский пакет не заменяет встроенный английский и не добавляет неизвестные ключи;
- отсутствующие английские ключи дают warning и используют английский текст во время работы;
- именованные параметры должны точно совпадать с английским сообщением.

Ошибки JSON или схемы не дают загрузить пакет. Ошибка отдельного перевода не обрушает UI:
LocaForge записывает диагностику и использует наиболее безопасное доступное сообщение.

## Обновление пакета

Когда LocaForge добавляет строки, сравните пакет с новым шаблоном или встроенным
`src/locaforge/resources/locales/en.json`. Добавьте ключи, сохраните параметры, не меняйте
`format_version` и снова запустите проверку.

Чтобы добавить язык в поставку, приложите JSON-пакет, тесты локализации и изменения обеих
версий документации: [английской](../README.md) и [русской](../README.ru.md).
