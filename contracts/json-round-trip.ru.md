# Контракт JSON round-trip

## Поддерживаемый вход

Корень — JSON object или array. Строки, выбранные настройкой импорта, становятся записями
перевода. Objects, arrays, числа, boolean, null, невыбранные строки, порядок ключей и Unicode
сохраняются как метаданные round-trip.

## Импорт

Каждая выбранная строка получает стабильный путь и идентификатор записи. Ключи object образуют
сегменты пути через точку, элементы array используют числовые индексы. Импорт не изменяет
исходный файл. Ошибочный JSON, неподдерживаемый корень, небезопасный mapping и повторяющиеся
пути проекта отклоняются до сохранения.

## Экспорт

Экспорт начинается с сохранённого исходного документа, заменяет только выбранные строки их
текущими переводами и записывает отдельный файл назначения. При отсутствии перевода остаётся
исходный текст. Операция транзакционна: ошибка проверки или записи не оставляет частичный файл.

Контракт гарантирует семантический, а не побайтовый JSON round-trip. Пробелы, отступы,
экранирование и финальный перенос строки могут нормализоваться; типы и невыбранные значения
меняться не должны.

## Приёмочные примеры

Для `{"menu":{"play":"Play"},"lives":3}` выбор `menu.play` и перевод `Играть` дают
`{"menu":{"play":"Играть"},"lives":3}`. Число остаётся числом.

Для `["One", {"enabled": true}]` выбор индекса `0` меняет только эту строку. Object и boolean
остаются неизменными. Если перевод пуст или отсутствует, сохраняется `"One"`.

## Ошибки

Ошибки importer/exporter содержат контекст файла и пути, достаточный для понятного сообщения
application layer. Адаптеры форматов возвращают domain/application-ошибки и не показывают UI dialogs.
